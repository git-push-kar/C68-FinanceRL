# Polyvalent Nifty paper-trading demo

Start with [PAPER_TRADING.md](PAPER_TRADING.md). The Finance workspace runs the selected Nifty native RL adapter on each scheduled rebalance in a historical paper account. It does not replay cached trained decisions or connect to a broker. Finance conversation was removed after a30-question factual audit of two model configurations; the inspector is explicit execution evidence.

Other original workspaces and routing source remain present. Their complete trained weights are not all bundled and their quality was not recertified. Finance requires the pinned full upstream InternVL3-2B snapshot plus the selected Git LFS policy weights and NPZ panel. No dependency on the temporary research checkout is needed to serve the Finance demo.

See ../docs/JOURNAL_RESEARCH_REPORT.md for the final method, all comparisons, uncertainty, limitations, failed experiments and verification. Historical source and every selected checkpoint are available in ../archives; remaining intermediate-weight recovery status is documented there.
