# Original SSD context reports

These are unchanged historical source documents from the SSD root, including the
original `C68_CONTEXT_BOMB.md`, `CONTEXT_BOMB.md`, `F_CONTEXT_BOMB.md` and combined
report. Some are identical aliases. Their descriptions, adapter choices and status
claims reflect earlier stages; they are not current verification of this demo or
of the other domains. Follow `../START_HERE.md` for the authoritative current state.

The original November 7 handover, including its source snapshot, evidence,
reference PDF/DOCX/PPTX documents and small migration packages, is preserved in
`../../archives/original-ssd-handover-20261107.zip` via Git LFS. Its per-file hashes
and source-to-destination mappings are in `../../archives/ssd_handover_manifest.json`.
Git metadata, environments and bytecode were excluded. Extract into a new directory.
